# results/

Raw CSVs, summaries and figures written by `python -m benchmarks.runner` and
`python -m benchmarks.analyze`. Commit the final paper runs (raw.csv, meta.json,
summary.md) so the numbers in the paper can be regenerated and checked.

`results/summaries/` holds the small committed tables (markdown and CSV) behind the charts in the
top-level README; regenerate the charts with `python scripts/make_readme_figures.py`.

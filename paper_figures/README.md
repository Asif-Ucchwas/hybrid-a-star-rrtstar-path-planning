# Paper Figures and Tables

This folder contains every figure and table used in the IEEE Access manuscript
**"Real-Time ROS2 Deployment of a Hybrid A*-Guided Adaptive-Corridor RRT* Path
Planner With Kalman Filter State Estimation for Autonomous Mobile Robots"**
(Asifuzzaman & Zargarzadeh, 2026), in the same sequence they appear in the
paper, with captions matching the manuscript exactly.

## Provenance / how these were generated

- **Figures 1–4** (benchmark charts) are generated from the 50-trial and
  density-sweep experimental data reported in Table 1 and Table 2. Reproduce
  the underlying benchmark with:
  ```bash
  python src/benchmark_50trials.py
  ```
- **Figure 5** (architecture diagram) is compiled from
  [`fig_architecture.tex`](../fig_architecture.tex) (TikZ/LaTeX source,
  standalone document class).
- **Figure 6** (Kalman filter validation) is fully reproducible via:
  ```bash
  python src/validate_kalman_filter.py
  ```
  which uses the actual deployed `KalmanFilter` class from
  [`ros2_integration/planner_nodes/planner_nodes/kalman_filter.py`](../ros2_integration/planner_nodes/planner_nodes/kalman_filter.py)
  against a synthetic noisy circular trajectory, and prints the resulting
  position-error reduction alongside saving the figure.
- **Table 3** (live planning latency) is measured directly from the deployed
  ROS2 nodes in the Gazebo Harmonic / TurtleBot3 simulation described in
  Section V of the paper, and is not regenerated by a standalone script.
